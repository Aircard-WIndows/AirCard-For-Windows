## Getting Started
1. Download 1.2.4.
2. Install 64-bit iTunes or Apple Mobile Device Support.
3. Run `aircard.exe`, Trust the iPhone, Scan.
4. Notes in `files/notes/`.

## FAQ

**is aircard safe?**
It writes Wallet / TelephonyUI cache art. Apple Pay credentials stay on the Secure Enclave.

**aircard-ios / aircard macos?**
Separate IPA and DMG. This zip is the Windows Rust exe.

## Requirements
Windows 10/11 x64. iPhone on iOS 18+. USB-C or Lightning for first pair.
